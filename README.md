### 🚀 Proyectos destacados

#### 📦 [PaperFlow](https://github.com/TU-USUARIO/paperflow) — Sistema Integral de Inventario y POS
`Next.js 16` `React 19` `TypeScript` `Supabase` `Tailwind CSS 4`
Arquitecté y desarrollé una aplicación full-stack de gestión de inventario y punto de venta, con esquema relacional PostgreSQL de 14 entidades, autenticación con Supabase Auth (cookies HttpOnly), rutas protegidas por Middleware y un dashboard analítico con KPIs del negocio.

#### 🐾 [VetCare Manager](https://github.com/TU-USUARIO/vetcare-manager) — Plataforma de Gestión de Pacientes Veterinarios
`React 18` `Node.js` `Express` `MongoDB` `JWT`
Plataforma full-stack MERN con arquitectura backend MVC, autenticación con JWT + bcrypt, autorización a nivel de recurso que aísla los datos entre veterinarios, y flujos de confirmación de cuenta y recuperación de contraseña vía correo.

#### 💅 [NailStudio Glam](https://github.com/TU-USUARIO/nailstudio-glam) — Landing Page de Conversión
`Next.js 16` `React 19` `TypeScript` `shadcn/ui`
Landing comercial para salón de belleza con arquitectura orientada a configuración (reutilizable como plantilla para distintos clientes), integración de WhatsApp Business y diseño responsivo mobile-first con SEO/Open Graph optimizado.

#### ✈️ [ViajaYa](https://github.com/TU-USUARIO/viajaya) — Plataforma Web de Agencia de Viajes
`Node.js` `Express` `Sequelize` `MySQL` `Pug`
Sitio de agencia de viajes con patrón MVC y renderizado del lado del servidor, catálogo de viajes gestionado dinámicamente vía Sequelize/MySQL y estructura de vistas modular con herencia de layouts en Pug.

#### 🌐 [Portafolio Personal](https://my-portafolio-fawn.vercel.app)
`HTML5` `CSS3` `JavaScript`
Sitio web personal totalmente responsivo para presentar proyectos, habilidades técnicas y formación profesional, con enfoque mobile-first mediante Flexbox y CSS Grid.
